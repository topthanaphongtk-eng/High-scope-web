# คู่มือติดตั้งฐานข้อมูล PostgreSQL (ฉบับเริ่มจากศูนย์)

> สำหรับคนที่ **ไม่เคยใช้ฐานข้อมูล / ไม่ถนัด software** มาก่อน
> ทำตามทีละขั้น ทำ **ครั้งเดียว** บนเครื่องที่จะเป็นเซิร์ฟเวอร์ (`MTH-dk-b12416`)

---

## ภาพรวม (อ่านก่อน 1 นาที)

โปรแกรม High Scope Capture เก็บข้อมูลรูปที่ถ่ายไว้ใน **ฐานข้อมูลกลาง** 1 ที่
ทุกเครื่อง (ทั้งโปรแกรมหน้างาน และหน้าเว็บ) มาดึงข้อมูลจากที่เดียวกัน

เรากำลังจะตั้ง "ฐานข้อมูลกลาง" นั้นด้วยโปรแกรมชื่อ **PostgreSQL**

มี 7 ขั้น:

| ขั้น | ทำอะไร | ใช้เวลา |
|---|---|---|
| 1 | ติดตั้งโปรแกรม PostgreSQL | ~10 นาที |
| 2 | สร้าง "ผู้ใช้" ชื่อ `highscope` | 2 นาที |
| 3 | สร้าง "ฐานข้อมูล" ชื่อ `highscope` | 1 นาที |
| 4 | สร้างตาราง (รันไฟล์ที่เตรียมไว้) | 2 นาที |
| 5 | เปิดให้เครื่องอื่นต่อเข้ามาได้ | 5 นาที |
| 6 | ใส่รหัสผ่านลงในโปรแกรม | 3 นาที |
| 7 | ทดสอบว่าใช้งานได้ | 2 นาที |

> 💡 ถ้าจะลองบนเครื่องเดียวก่อน (โปรแกรมกับฐานข้อมูลอยู่เครื่องเดียวกัน) **ข้ามขั้นที่ 5 ได้** แต่ถ้ามีหลายเครื่องมาต่อ ต้องทำขั้นที่ 5

---

## ขั้นที่ 1 — ติดตั้ง PostgreSQL

1. เปิดเว็บ **https://www.postgresql.org/download/windows/** → กดปุ่ม **"Download the installer"**
2. เลือกเวอร์ชันล่าสุดสำหรับ **Windows x86-64** แล้วดาวน์โหลด
3. ดับเบิลคลิกไฟล์ที่โหลดมา → กด **Next** ไปเรื่อย ๆ
4. หน้า **"Select Components"** ติ๊กให้ครบ: ✅ PostgreSQL Server  ✅ pgAdmin 4  ✅ Command Line Tools
5. หน้า **"Password"** — ตั้งรหัสผ่านของผู้ดูแลระบบ (ชื่อผู้ใช้คือ `postgres`)
   > ✍️ **จดรหัสนี้ไว้ให้ดี** เรียกว่า "รหัส postgres" จะใช้ตอนเข้า pgAdmin
6. หน้า **"Port"** — ปล่อยเป็น **5432** (ค่ามาตรฐาน อย่าเปลี่ยน)
7. กด Next จนจบ → **Finish** (ถ้ามี Stack Builder เด้งขึ้นมา กด Cancel ได้ ไม่ต้องใช้)

ตอนนี้เครื่องนี้มีฐานข้อมูลทำงานอยู่แล้ว เปิดโปรแกรม **pgAdmin 4** จากเมนู Start

---

## ขั้นที่ 2 — สร้างผู้ใช้ `highscope`

1. เปิด **pgAdmin 4** (ครั้งแรกอาจถามให้ตั้ง "master password" ของ pgAdmin — ตั้งอะไรก็ได้ แล้วจำไว้)
2. ด้านซ้ายกดสามเหลี่ยมขยาย **Servers → PostgreSQL** → ใส่ **รหัส postgres** (จากขั้น 1 ข้อ 5)
3. คลิกขวาที่ **Login/Group Roles** → **Create → Login/Group Role…**
4. แท็บ **General** → ช่อง Name พิมพ์: `highscope`
5. แท็บ **Definition** → ช่อง Password พิมพ์รหัสผ่านที่จะใช้กับแอป
   > ✍️ **จดรหัสนี้ไว้** เรียกว่า "รหัส highscope" จะเอาไปใส่ในโปรแกรมตอนขั้น 6
6. แท็บ **Privileges** → เปิดสวิตช์ **"Can login?"** ให้เป็น **Yes**
7. กด **Save**

---

## ขั้นที่ 3 — สร้างฐานข้อมูล `highscope`

1. ด้านซ้าย คลิกขวาที่ **Databases** → **Create → Database…**
2. ช่อง **Database** พิมพ์: `highscope`
3. ช่อง **Owner** เลือก: `highscope` (ผู้ใช้ที่เพิ่งสร้าง)
4. กด **Save**

ด้านซ้ายจะมี `highscope` โผล่ขึ้นมาใต้ Databases

---

## ขั้นที่ 4 — สร้างตาราง (รันไฟล์ที่เตรียมไว้)

ตารางทั้งหมดเตรียมไว้ในไฟล์ **`db/schema_postgres.sql`** (อยู่ในโฟลเดอร์โปรแกรม) แค่เอามารัน

1. ด้านซ้าย คลิกที่ฐานข้อมูล **highscope** (ให้เป็นแถบสีน้ำเงิน)
2. เมนูบน → **Tools → Query Tool** (จะเปิดช่องว่าง ๆ ให้พิมพ์/วางคำสั่ง)
3. ในช่อง Query Tool กดไอคอน **เปิดไฟล์** (รูปโฟลเดอร์ 📂) → เลือกไฟล์ `db/schema_postgres.sql`
4. กดปุ่ม **▶ Run** (หรือกดปุ่ม **F5**)
5. ด้านล่างขึ้น **"Query returned successfully"** = สำเร็จ ✅

**ตรวจว่าได้ตารางจริง:** ด้านซ้ายขยาย `highscope → Schemas → public → Tables`
ต้องเห็น 2 ตาราง: **captures** และ **capture_files**

---

## ขั้นที่ 5 — เปิดให้เครื่องอื่นต่อเข้ามาได้

> ข้ามขั้นนี้ได้ถ้าทดสอบบนเครื่องเดียวกัน แต่ถ้ามีเครื่องหน้างาน/เว็บอยู่คนละเครื่อง **ต้องทำ**

ต้องแก้ไฟล์ตั้งค่า 2 ไฟล์ อยู่ในโฟลเดอร์ (ปกติ):
`C:\Program Files\PostgreSQL\16\data\`  *(เลข 16 = เวอร์ชัน อาจต่างกัน)*

> ⚠️ ต้องเปิด Notepad แบบ **Run as administrator** ถึงจะบันทึกไฟล์ในโฟลเดอร์นี้ได้
> (กดปุ่ม Start → พิมพ์ Notepad → คลิกขวา → **Run as administrator** → เมนู File → Open → ไปเลือกไฟล์)

**ไฟล์ที่ 1: `postgresql.conf`**
- หาบรรทัดที่ขึ้นต้นว่า `#listen_addresses` แก้เป็น (ลบ `#` ข้างหน้าออกด้วย):
  ```
  listen_addresses = '*'
  ```

**ไฟล์ที่ 2: `pg_hba.conf`**
- เลื่อนลงล่างสุด เพิ่มบรรทัดนี้ต่อท้าย (อนุญาตเครื่องในวง LAN ของโรงงาน):
  ```
  host    highscope    highscope    10.50.0.0/16    scram-sha-256
  ```

**บันทึกทั้ง 2 ไฟล์** แล้ว **รีสตาร์ทบริการ**:
- กด Start → พิมพ์ **Services** → เปิด → หาบริการที่ขึ้นต้นว่า **postgresql-x64-** (เลขท้ายคือเวอร์ชัน เช่น `-16`, `-17`) → คลิกขวา → **Restart**

**เปิด Firewall ให้พอร์ต 5432** (เปิด Command Prompt แบบ Run as administrator แล้ววาง):
```
netsh advfirewall firewall add rule name="PostgreSQL" dir=in action=allow protocol=TCP localport=5432
```

---

## ขั้นที่ 6 — ใส่รหัสผ่านลงในโปรแกรม

ใช้ "รหัส highscope" (จากขั้น 2 ข้อ 5)

**โปรแกรมหน้างาน (Desktop):** วิธีง่ายสุดคือตั้งในตัวโปรแกรมเลย
- เปิดโปรแกรม High Scope Capture → เมนู **File → Settings**
- กรอก: **Postgres host** = `MTH-dk-b12416`, database = `highscope`, user = `highscope`, password = รหัส highscope
- กด **Save**

**หน้าเว็บ (Web):** เปิดไฟล์ `web\.env.local` ด้วย Notepad แล้วเติมรหัสตรงบรรทัด `PGPASSWORD=`
```ini
PGHOST=MTH-dk-b12416
PGDATABASE=highscope
PGUSER=highscope
PGPASSWORD=ใส่รหัส highscope ตรงนี้
PGPORT=5432
```

---

## ขั้นที่ 7 — ทดสอบว่าใช้งานได้

- **Desktop:** เปิดโปรแกรม → ลอง sign-in + ทำงานปกติ ถ้าไม่มีหน้าต่างแดงเด้งว่า "Database not reachable" = ต่อได้แล้ว ✅
- **Web:** เปิดเว็บ (หน้า `/`) ถ้าโชว์รายการรูป/ตัวเลขได้โดยไม่ error = ต่อได้แล้ว ✅
  *(ตอนแรกจะว่างเปล่าเพราะยังไม่มีข้อมูล — เป็นเรื่องปกติ พอ operator กด Confirm รูปแรก ข้อมูลจะเริ่มเข้า)*

## เจอปัญหา? (ภาษาคน)

| ข้อความที่เห็น | แปลว่า | ทำยังไง |
|---|---|---|
| `no pg_hba.conf entry for host ...` | เครื่องนี้ยังไม่ได้รับอนุญาตให้ต่อ | ทำ **ขั้นที่ 5** ไฟล์ `pg_hba.conf` ให้ครบ + รีสตาร์ทบริการ |
| `password authentication failed` | รหัสผ่านผิด | เช็ค "รหัส highscope" ให้ตรงกับที่ตั้งในขั้น 2 |
| `could not connect to server` / `timed out` | ต่อเครื่องไม่ถึง | เช็คว่าเปิด Firewall พอร์ต 5432 + `listen_addresses = '*'` + เครื่องเปิดอยู่/ชื่อเครื่องถูก |
| `database "highscope" does not exist` | ยังไม่ได้สร้างฐานข้อมูล | ทำ **ขั้นที่ 3** |
| `relation "captures" does not exist` | ยังไม่ได้สร้างตาราง | ทำ **ขั้นที่ 4** (รันไฟล์ schema) |

> ติดตรงไหนให้ก๊อปข้อความ error มาถาม จะช่วยดูให้
